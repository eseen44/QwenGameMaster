# In Character Score

## Znaczenie

`In Character Score` mierzy zgodność zadeklarowanego działania z aktualnym modelem Lucana, a nie jego moralną wartość. Ocena uwzględnia motywację, kontekst, relacje, dotychczasowe precedensy i świadomy rozwój postaci.

## Skala i modyfikator

| Wynik | Modyfikator |
|---:|---:|
| 9–10 | +15 |
| 7–8 | +10 |
| 5–6 | 0 |
| 3–4 | -5 |
| 1–2 | -15 |
| 0 | -30 |

Wynik należy ustalić tylko wtedy, gdy test rzeczywiście dotyczy działania Lucana. Test świata albo NPC nie otrzymuje modyfikatora charakteru Lucana.

## Interpretacja

- 9–10: zachowanie mocno zakorzenione w aktualnej postaci.
- 7–8: naturalne i dobrze uzasadnione.
- 5–6: neutralne, mieszane albo mieszczące się w kilku sprzecznych cechach.
- 3–4: nietypowe, ale posiadające realne oparcie w sytuacji lub więzi.
- 1–2: silnie sprzeczne z aktualnym modelem postaci.
- 0: działanie bez wiarygodnej motywacji albo jawnie odrzucające ustaloną postać.

Rozsądek, uprzejmość lub empatia nie są automatycznie zachowaniem poza postacią. Liczy się powód, cena oraz osoba, wobec której Lucan działa.

## Asymetryczna zmiana postaci

- Lucan już potrafi być bezwzględny; poprawa relacji nie odbiera mu tej zdolności.
- Powtarzane, kosztowne i znaczące działania początkowo oceniane na 0–5 mogą tworzyć precedens.
- Precedens zmniejsza obcość podobnego działania w przyszłości, ale nie przepisuje automatycznie całej osobowości.
- Zmiany zapisujemy w `player/personality.md` jako wyjątek, więź albo nową sprzeczność wraz ze źródłem w dzienniku.
