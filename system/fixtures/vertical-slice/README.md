# Pionowy wycinek mechaniki

Te dane służą do kalibracji silnika i testów regresyjnych. Nie są aktywnym kanonem kampanii Lucana. Wartości Spideya są roboczymi hipotezami opartymi na dokonaniach z historii i wymagają osobnej akceptacji pakietu migracyjnego.

Wycinek obejmuje Spideya, człowieka, konia, kamienny mur, Varkhena, ugryzienie, jad, nekrozę, `Numb`, baterię energii i przygotowaną sekwencję obezwładniania.
