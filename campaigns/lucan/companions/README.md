# Kontrolowane byty

Tutaj trafiają chowańce, sługi, przywołania, konstrukty i roje związane z Lucanem. Wszystkie otrzymują stabilny identyfikator. Identyczne jednostki mogą być zapisane jako grupa; nazwana lub trwale zmodyfikowana jednostka otrzymuje własny plik.

Schemat znajduje się w `templates/companion/companion.yaml`.
