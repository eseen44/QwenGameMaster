# Niekanoniczna gałąź po przejęciu Varkhena

Po zlokalizowaniu granicy w pełnym transkrypcie materiał następujący po skutecznym przejęciu Varkhena zostanie zachowany tutaj jako oddzielna gałąź referencyjna.

Nie wolno na jego podstawie aktualizować:

- wiedzy Lucana ani NPC;
- bieżących rozkazów Spideya lub innych kontrolowanych bytów;
- czasu, zegarów i reakcji świata;
- aktywnej sceny;
- kanonicznego dziennika wydarzeń.

Retrospektywne stwierdzenie z tej gałęzi może jedynie wskazać fakt do odnalezienia przed granicą. Bez wcześniejszego źródła pozostaje `uncertain`.
